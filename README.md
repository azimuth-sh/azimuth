# Azimuth

Azimuth lets people direct and review software work at the level of intent, and it proves that the code matches that intent.

## Status

Azimuth is being rewritten from its design. The repository holds the design and no code yet.

- The design is [docs/design.md](docs/design.md). It is the single source for the rewrite.
- The earlier implementation is in the history of this repository. The packages published from it as `@azimuth-sh/*` in the `0.1.0-alpha` series receive no fixes.
- Versions of the rewrite start at `0.2.0-alpha.1`.
