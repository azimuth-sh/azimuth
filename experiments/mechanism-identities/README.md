# Mechanism identity conformance

This experiment proves the mechanism-identity boundary with the seven public extractor
families: C++, Python, Go, Rust, .NET, JVM and TypeScript/JavaScript. It creates two disposable
copies of every declared language or project root, compiles them with their real toolchain and
invokes the public extractor CLI. No consumer checkout, service, registry or network dependency is
used.

Each pair must retain its semantic `site`, typed raw `binding`, three-field companion Artifact and
source fingerprint while its accountable `file` locator moves. The gate checks the exact
seven-field implementation shape, excludes filesystem locators from semantic identities and
exercises the authority profile appropriate to each ecosystem: overloads and nested types,
receivers and positional generics, Rust trait identity, compiler module identity and the
fail-closed profiles that cannot yet be qualified safely.

The experiment then gives the real core both relocated manifest sets. Its isolated synthetic
standard Claims exist only so current Claim Judgment and Challenge planning can be compared; they
establish no evidence or credibility for Azimuth's routine framework Claims. As relocation changes
the workspace and raw source locators, raw manifest, complete-model and launch fingerprints must
change. The assembled SourceIdentity, mechanism and companion identities, Claim Judgment
fingerprints, Challenge targets, selections and semantic scope fingerprints must remain equal.
All 14 selected Challenges compare exact anchor and input components. Every launch route must
project exactly its source-backed scope, and every projected source locator must move while its
kind, id, fingerprint and non-file source metadata remain equal.

Two separately emitted C++ markers deliberately share one raw kind and site. They assemble in
different areas without collision because their keys are `<area>|<kind>|<site>`; mapping both into
one area fails before publication. Strict invalid fixtures cover every native, managed and
TypeScript family. Superseded records missing `site`, deriving `binding` and companion id from a
file,
or mismatching the marker companion all fail without output. A retired alpha manifest key provides
an additional proof that no compatibility reader remains.

Run the complete disposable gate with:

```text
./experiments/mechanism-identities/check.sh
```

The script needs the repository-supported Python, Clang, Go, Rust, .NET, Java and Node toolchains.
It writes only tool build caches and one trapped temporary directory. Running it twice must produce
the same assertions and no retained experiment state.
