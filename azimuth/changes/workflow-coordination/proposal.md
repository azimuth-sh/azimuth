# Change: workflow-coordination

Status: active

## Intent

Implement harness-agnostic, explicit workflow coordination through independently reviewed authoring and exact-Subject assurance. The user authorized implementation of this bounded first increment. Deployment, acceptance and archival automation remain outside this increment.

## Scope

A request, configured workflow definition and explicit repository roots produce read-only task handoffs. Conditional, idempotent updates retain work results and adverse reviews. Independent authoring reviews are distinct from existing Method Qualification, Applicability Decision and Claim Judgment records. Candidate model revisions belong to an already configured ASS project and do not replace accepted authority.

## Boundaries

No agent invocation, shell discovery, automatic deployment, decisions manufactured from execution, consumer-specific fixtures, backward compatibility or tests. Existing review assessment is reused. Operational state is separate from examined source identity. Authenticated ASS ingestion verifies reviewer identity; local coordination alone is not authentication.

## Completion

Build CLI and service; inspect strict contracts; exercise product commands using synthetic non-test authoring inputs. Record remaining gates and tooling limitations explicitly. Do not finalize, archive, publish or commit implicitly.
