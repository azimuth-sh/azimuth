# Migration: 0.1.0-alpha.9 to 0.1.0-alpha.10

Migration line: alpha-requirement-scenario
Account transformation: none

Alpha.10 keeps the alpha.9 account grammar, so authored accounts need no edit. Run `azimuth update` to align the installation with this release.

Changes:
- The alpha.9 release tag never published: its release workflow could not start the macOS native build because the retired `macos-14` runner was no longer available. Alpha.10 builds the `aarch64-apple-darwin` archive on `macos-15` and carries the alpha.9 behavior unchanged.
- The alpha.9 version is permanently consumed; installations pinned to alpha.9 move directly to alpha.10 with no further edits.
