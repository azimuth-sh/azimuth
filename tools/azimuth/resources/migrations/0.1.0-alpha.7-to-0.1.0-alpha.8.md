# Migration: 0.1.0-alpha.7 to 0.1.0-alpha.8

Migration line: alpha-requirement-scenario
Account transformation: none

Alpha.8 keeps the alpha.7 account grammar, so authored accounts need no edit. Run `azimuth update` to replace the agent integrations and skills.

Changes:
- The Claude Code hook now runs the provenance capture on every shell call, and the capture decides which calls record a workflow result.
- `workflow update` refuses a new attempt that has no captured or declared provenance unless it is given `--provenance unknown`.
- `azimuth provenance reconstruct` appends attestations to `<change>/provenance/attestations.json`.
- Intent deltas accept `## Replace term:`.
- `workflow init --predecessor` carries the predecessor's current results into the fresh instance as `carried` history entries.

An alpha.7 CLI rejects instances that hold carried entries. Upgrade every CLI that records results for a change before you restart its workflow.

Instances pinned to alpha.7 workflow definitions remain unreadable to an alpha.8 CLI wherever they name a retired task kind. Abandon such an instance with the alpha.7 CLI before you run `azimuth update`, because update removes the skills its handoffs reference. Then initialize a fresh instance with `--predecessor`.
