# Migration: 0.1.0-alpha.4 to 0.1.0-alpha.5

Migration line: alpha-claim-case
Account transformation: none

Alpha.5 accepts Claim and Case bodies as non-empty free-form Markdown instead of interpreting
Gherkin steps. Existing alpha.4 Claim and Case text remains valid, so repository accounts require
no authored semantic edit. Alpha.5 preserves body line structure that alpha.4 normalized, and its
Case fingerprint representation changes; existing reviewed decision fingerprints are therefore
not portable and normal validation may require them to be reviewed again. Consumers of model
export or traceability JSON must adopt protocol version 4 and read each Case's `statement` or
`case_statement` field instead of the former structured `steps` array.
