# Migration: 0.1.0-alpha.6 to 0.1.0-alpha.7

Migration line: alpha-requirement-scenario
Account transformation: automatic authored-syntax rewrite

Alpha.7 replaces the `alpha-claim-case` line with `alpha-requirement-scenario`: Claims become Requirements, specification Cases become Scenarios, assurance Subjects become Verification Targets, Check Observations become Check Results, Verification Context becomes Execution Context (including the `Execution Context:` label of Evidence Bindings and Method Qualifications), Challengers become Verification Challenges, and Claim Review and Claim Health become Requirement Review and Requirement Status. Obligations, stable identifiers, evidence semantics and assessment rules do not change.

Run `azimuth migrate plan`, then `azimuth migrate apply` and `azimuth update`. The account rewrite is described in the `alpha-claim-case-to-alpha-requirement-scenario` migration. Every renamed wire format takes a new version with no compatibility reader, so producers and consumers upgrade together; historical Runs, reviews, manifests and archives remain immutable and are not re-fingerprinted.
