# Azimuth project account

This directory contains the project's accepted intent, proposed transitions, exploratory research and decision policies.

## Directory structure

- `model/` contains accepted current intent and mechanisms.
- `changes/` contains proposed and active transitions.
- `changes/archive/` contains accepted transition records.
- `explorations/` contains non-normative research and decision shaping.
- `explorations/archive/` contains completed research records.
- `standards/verification.md` contains current Decision Policies and the Challenge Schedule.
- `workspace.json` declares project areas, surfaces and obligations.
- `installation.json` records CLI-managed Azimuth resources and adopted components.

## Lifecycle

Azimuth work normally proceeds through exploration, proposal, approval, implementation, finalization and archival. Agents execute each stage through the installed Azimuth skills. This README provides orientation only and does not define stage procedures or artifact formats.

## Common commands

```text
azimuth --version
azimuth reference list
azimuth explore list
azimuth change list
azimuth update --check
azimuth validate
azimuth report traceability
azimuth --help
```

Use command help and the installed Azimuth skills for the capabilities available in the installed version.

## Authority

Repository instructions and Azimuth artifacts define project authority. External documentation is supplementary and is not required to execute an Azimuth stage.
