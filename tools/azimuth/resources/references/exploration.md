# Exploration reference

An exploration is non-normative research above individual changes. Its active stable id is lower-kebab and undated; `Created: YYYY-MM-DD` belongs in the anchor. The required file is `exploration.md`; use `research.md` for substantial sourced findings and `change-map.md` for several likely changes.

An exploration moves from `Status: exploring` to `Status: approved` only after explicit approval of the actual files. Approval does not authorize a candidate change. Archival is a later explicit operation and moves the unchanged approved package to `archive/YYYY-MM-DD-<id>`.
